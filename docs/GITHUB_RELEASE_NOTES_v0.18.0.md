# AutoGraphFM v0.18.0 — Portfolio-ready public release

## Highlights

- End-to-end automotive demand forecasting workflow from bilingual ingestion to governed release and realized-outcome feedback.
- Statistical, Ridge, GRU, regime-aware ensemble, and controlled graph-learning baselines.
- Leakage-safe rolling-origin evaluation and validation-only model selection.
- Identity, permuted, static, adaptive, and sparse graph falsification controls.
- Stability-selected graph discovery with 83.3% controlled Precision@K and 1.00 cross-seed edge Jaccard.
- 108 automated tests across data, database, forecasting, graph, monitoring, governance, and reporting.

## Evidence boundary

The release includes real aggregate-market forecasting evidence and controlled graph-identifiability evidence. It does **not** claim that graph learning is superior on the complete real vehicle-level panel. That claim remains locked behind the real-panel challenge described in `docs/CLAIMS_AND_LIMITATIONS.md`.
